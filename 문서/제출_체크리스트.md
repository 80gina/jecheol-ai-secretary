## D. 제출 스크린샷 7장

| # | 무엇을 | 찍는 법 |
|---|---|---|
| 1 | 데이터 요약이 보이는 채팅 | 위쪽 채팅 + **🛒 필요한 재료** 카드 + 오른쪽 판정이 **한 화면에** |
| 2 | 데이터 관리 (CRUD 1개 동작) | 오른쪽 `🗂️ 데이터 관리` 를 펼치고, 추가 직후 목록이 갱신된 상태 |
| 3 | 대화 기록 불러오기 | 오른쪽 목록 클릭 → 대화가 다시 표시되고 항목이 하이라이트 |
| 4 | Swagger UI | `/docs` 에서 엔드포인트 25개가 보이게 |
| 5 | 도구 호출 추적 (보너스①) | 채팅 하단 `🔧 find_extreme({...})` |
| 6 | 그래프 + 다크 모드 (보너스②) | 밝은 화면 / 어두운 화면 각 1장 |
| 7 | 스모크 테스트 | `🎉 전체 통과` 가 보이게 |
| 8 | **조건 추천** (보너스②) | `국·찌개`+`밥반찬` 선택 후 추천 결과 카드들 |
| 9 | **시각화 4종** (보너스②) | 평가 레이더 / SWOT / 히트맵 / 분포 각 1장 (또는 대표 2장) |
| 10 | **향후 추이선** (보너스②) | 점선·띠·"여기부터 예측" 경계 + 아래 계산 방법 문구가 함께 보이게 |

> 📸 **1·3·5번은 OpenAI 키가 있어야 찍을 수 있습니다.** `backend/.env` 의 `OPENAI_API_KEY=` 뒤에 키를 넣고 서버를 다시 켜세요.

### 스크린샷 1·5번용 질문 예시

키를 넣은 뒤 이 순서로 물어보면 필요한 화면이 다 나옵니다.

```
1) 김치찌개 하려는데 재료값 어때?  → 장바구니 카드가 뜸 (스크린샷 1)
2) 6월 중에 제일 쌌던 날은?        → find_extreme 호출 (스크린샷 5)
3) 배추가 비싼데 뭘 대신 쓸까?     → suggest_alternative 호출 (스크린샷 5 대안)
4) 다음 달에 사는 게 나아?         → get_price_forecast 호출 (도구 11종 중 신규)
5) 도시락 반찬 추천해줘            → recommend_dishes 호출
```

> 4번 답변에서 GPT가 **"~할 것입니다"라고 단정하지 않고 "계산됩니다 / 다만 ~는 반영되지 않습니다"**
> 라고 답하는지 확인하세요. 그게 프롬프트 9~11번 규칙이 실제로 먹히는지 보는 자리입니다.
